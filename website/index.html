06 — FAQ

常见疑问。Common questions.

没有 API Key 或 Meshy Key 也能上手吗？Can I start without API keys or a Meshy key?+
可以。登录 ChatGPT 订阅（Codex）即可直接驱动对话、操作 Houdini 节点并用 gpt-image-2.5* 生图改图，全程零 API Key；需要 3D 生成或角色绑骨时再配 Meshy Key。Yes — sign in with your ChatGPT plan (Codex) for chat, Houdini node building, and gpt-image-2.5* image generation with zero API keys. Add a Meshy key only for 3D meshes & rigging.
需要给 Houdini 装 Python 依赖吗？Do I need to install Python packages in Houdini?+
完全不需要。Windows 安装包自带独立运行环境，自动探测 Houdini（19.5 / 20.5 / 21+）并安装轻量桥接 package，不改系统 Python。Never. The standalone installer bundles its own runtime and installs a tiny auto-bridge package for Houdini 19.5–21+.
怎么防止 AI 改坏复杂工程？How is my Houdini scene protected?+
Ask / Plan 模式在工具层硬拦截所有写操作；可开启「确认模式」逐条审批；Agent 每批节点改动都带 Keep / Undo 一键回滚。Ask & Plan hard-block mutations, Confirm Mode approves each step, and every batch edit includes 1-click Keep / Undo.
可以接本地大模型、完全离线吗？Can I use local LLMs for full privacy?+
支持。在「设置 → 模型与 Provider」添加 LM Studio / vLLM / 内网兼容端点即可全程本机推理，数据不出内网。Yes — add LM Studio, vLLM, or any private OpenAI/Anthropic-compatible endpoint in Settings for 100% local inference.
